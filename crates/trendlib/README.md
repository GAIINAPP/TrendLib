# trendlib

Fast, tested technical-analysis indicators with a Rust core.

This crate is the computation core of [TrendLib](https://github.com/GAIINAPP/TrendLib).
It has no runtime dependencies and forbids `unsafe`. The Python package
`trendlib` wraps it through PyO3.

Indicators land from milestone M1 onwards; see `docs/MILESTONES.md` in the
repository.
