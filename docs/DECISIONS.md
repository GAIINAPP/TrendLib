## Settled

| ID | Decision | Why |
| --- | --- | --- |
| D1 | Name **TrendLib**. PyPI `trendlib`, crates.io `trendlib`, Python import `import trendlib as tl`. | Both registry names were free on 2026-10-04. |
| D2 | License **MIT OR Apache-2.0** (dual). Files `LICENSE-MIT`, `LICENSE-APACHE`. Contributions under DCO (`Signed-off-by:`), no CLA. | Maximum adoption; Apache adds a patent grant; Rust ecosystem norm. |
| D3 | **Rust core + PyO3 bindings, built with maturin**, one **abi3** wheel per platform, **Python ≥ 3.11**. | One fast implementation; small release matrix; Python 3.10 reaches end of life in Oct 2026. |
| D4 | Single source of truth = one folder per indicator **inside the core crate** (`crates/trendlib/src/indicators/<name>/`). | `cargo publish` and the PyPI sdist only ship files under a crate's folder. |
| D5 | A code generator (`cargo xtask generate`) produces registry, bindings, Python wrappers, type stubs and docs pages from `spec.yaml`. It does **not** generate algorithms. | TA-Lib's discipline without TA-Lib's multi-language ports. |
| D6 | For indicators TA-Lib also has, TrendLib uses **TA-Lib's computation conventions and TA-Lib's defaults**, so TA-Lib can serve as the oracle. Exceptions are listed in `CONVENTIONS.md` § Deviations. | An executable, independent oracle beats any written spec. |
| D7 | Outputs are **aligned to input length**, warm-up bars `NaN` (float) or `0` (integer outputs). | Matches what Python users expect and what ta-lib-python already returns. |
| D8 | **Leading NaNs are skipped; a NaN or ±inf after the first valid bar raises.** | A loud error beats silently wrong values. |
| D9 | **No global state**, including no global "unstable period" setting. | Thread safety; reproducibility. |
| D10 | **Timestamps must be timezone-aware** (or int64 epoch nanoseconds, read as UTC). Naive datetimes raise. | Session anchoring is meaningless without a zone. |
| D11 | Outputs are **descriptive**: no names or docs that read as a trade instruction (buy, sell, entry, exit, target, recommendation, "signal" meaning act now). Established indicator terms such as MACD's signal line are allowed. | GAIIN's regulatory posture. |
| D12 | Lowercase Python functions use TrendLib parameter names (`period`); uppercase aliases (`tl.RSI`) use ta-lib-python's names (`timeperiod`) and return TA-Lib's output names. Both compute identically. | Easy migration from TA-Lib without inheriting its naming everywhere. |
| D13 | Golden test inputs are **synthetic, seeded data** generated by a committed script. No exchange data is committed, except up to 30 rows of daily OHLC per human-transcribed oracle file (`TESTING.md` § 2). | Exchange data redistribution is licensed. |
| D14 | Docs site: MkDocs with the Material theme, published to GitHub Pages. | Standard for Python libraries; Markdown in, static site out. |
