# Decisions

Settled decisions are not reopened without a human. Open questions must be asked,
not guessed. Claude Code appends to "Assumptions pending review" when it has to
proceed on a judgment call.

## Settled

| ID | Decision | Why |
| --- | --- | --- |
| D1 | Name **TrendLib**. PyPI `trendlib`, crates.io `trendlib`, Python import `import trendlib as tl`. | Both registry names were free on 2026-10-04. |
| D2 | License **MIT OR Apache-2.0** (dual). Files `LICENSE-MIT`, `LICENSE-APACHE`. Contributions under DCO (`Signed-off-by:`), no CLA. | Maximum adoption; Apache adds a patent grant; Rust ecosystem norm. |
| D3 | **Rust core + PyO3 bindings, built with maturin**, one **abi3** wheel per platform, **Python ≥ 3.11**. | One fast implementation; small release matrix; Python 3.10 reaches end of life in Oct 2026. |
| D4 | Single source of truth = one folder per indicator **inside the core crate** (`crates/trendlib/src/indicators/<name>/`). | `cargo publish` and the PyPI sdist only ship files under a crate's folder. |
| D5 | A code generator (`cargo xtask generate`) produces registry, bindings, Python wrappers, type stubs and docs pages from `spec.yaml`. It does **not** generate algorithms. | TA-Lib's discipline without TA-Lib's multi-language ports. |
| D6 | For indicators TA-Lib also has, TrendLib uses **TA-Lib's computation conventions and TA-Lib's defaults**, so TA-Lib can serve as the oracle. Exceptions are listed in `CONVENTIONS.md` § Deviations. | An executable, independent oracle beats any written spec. |
| D7 | Outputs are **aligned to input length**, warm-up bars `NaN` (float) or `0` (integer outputs). | Matches what Python users expect and what ta-lib-python already returns. |
| D8 | **Leading NaNs are skipped; a NaN or ±inf after the first valid bar raises.** | A loud error beats silently wrong values. |
| D9 | **No global state**, including no global "unstable period" setting. | Thread safety; reproducibility. |
| D10 | **Timestamps must be timezone-aware** (or int64 epoch nanoseconds, read as UTC). Naive datetimes raise. | Session anchoring is meaningless without a zone. |
| D11 | Outputs are **descriptive**: no names or docs that read as a trade instruction (buy, sell, entry, exit, target, recommendation, "signal" meaning act now). Established indicator terms such as MACD's signal line are allowed. | GAIIN's regulatory posture. |
| D12 | Lowercase Python functions use TrendLib parameter names (`period`); uppercase aliases (`tl.RSI`) use ta-lib-python's names (`timeperiod`) and return TA-Lib's output names. Both compute identically. | Easy migration from TA-Lib without inheriting its naming everywhere. |
| D13 | Golden test inputs are **synthetic, seeded data** generated by a committed script. No exchange data is committed, except up to 30 rows of daily OHLC per human-transcribed oracle file (`TESTING.md` § 2). | Exchange data redistribution is licensed. |
| D14 | Docs site: MkDocs with the Material theme, published to GitHub Pages. | Standard for Python libraries; Markdown in, static site out. |
| D15 | **No data source lives in the library.** TrendLib accepts arrays and frames only, never a connection, driver, DSN or table name. The input frame contract and the loader patterns that satisfy it are documented in `DATA_INTEGRATION.md`. | Keeps the core crate dependency-free and the non-goal in `SPEC.md` § 3 honest. Callers own credentials, pooling and caching, so a schema change never becomes a library upgrade. |

## Assumptions pending review

A1 (M0, 2026-10-04): `<org>` placeholders were filled with the live remote,
`github.com/GAIINAPP/TrendLib`, in `pyproject.toml`, `CONTRIBUTING.md`, the issue
templates and `RELEASE.md` section 2 — a placeholder would ship a broken URL in the
package metadata, and the remote is observable. Cheap to change; Q1 still needs a
human answer before M3 because Trusted Publishing binds owner and repository.

A2 (M0, 2026-10-04): `project.urls.Documentation` points at the GitHub Pages default
`https://gaiinapp.github.io/TrendLib/` while Q5 is open. Change it in M5 if a custom
domain is chosen.

A3 (M0, 2026-10-04): `.github/pull_request_template.md`, the two issue templates and
`.claude/skills/new-indicator/SKILL.md` are described as "provided" by
`MILESTONES.md` and `CLAUDE.md` but were not in the repository, so M0 wrote them.

A4 (M0, 2026-10-04): the synthetic datasets are built from the standard library's
`random.Random`, not NumPy. CPython documents its Mersenne Twister stream; NumPy
promises no cross-version stream, which `TESTING.md` section 3 itself warns about.

A5 (M0, 2026-10-04): `testdata/daily_2000.csv` carries a `date` column (naive ISO
date, the way a SQL `DATE` reads back) and `testdata/intraday_5m_20d.csv` a
`timestamp` column (int64 epoch nanoseconds UTC). `TESTING.md` section 3 specifies
only the intraday one.

A6 (M0, 2026-10-04): the intraday dataset is 20 consecutive weekdays from Monday
2026-01-05, so it contains four weekend gaps rather than the single gap
`TESTING.md` section 3 mentions. Any 20 consecutive trading sessions span four
weekends; the requirement is read as "the series contains a weekend gap".

A7 (M0, 2026-10-04): `*.md` is excluded from ruff. Current ruff reformats Python
blocks inside Markdown, which would flatten the aligned explanatory comments the
docs rely on. Ruff still lints and formats every `.py` file.

A8 (M0, 2026-10-04): the CI step that installs TA-Lib is `continue-on-error`
everywhere except ubuntu + Python 3.11, so a platform with no wheel skips the parity
suite instead of failing the build, while one job always has the oracle.

A9 (M0, 2026-10-04): `crates/trendlib` has its own short `README.md`, included as the
crate docs, because `cargo publish` ships only files under the crate folder (D4) and
the repository README is two levels up.

A10 (M0, 2026-10-04): pinned pyo3 0.29 with numpy 0.29 (the matching pair), Rust
edition 2024 and toolchain 1.95. `extension-module` is a default feature of
`trendlib-py` so `cargo test --workspace` never has to link libpython.
